## Fixed

- **Selecting text in code blocks, table headers and inline code.** The
  selection highlight was drawn underneath the document, so anything with its
  own background covered it: a selection crossing a code block looked like it
  had skipped it, and selecting inside one looked like it did nothing. Copy
  always worked, but you couldn't see what you'd selected. The highlight now
  shows everywhere, and on long code lines it stops at the edge of the code
  panel instead of running past it.
