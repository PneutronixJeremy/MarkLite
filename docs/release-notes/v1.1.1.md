## Fixed

- **Crash on documents containing an `xml`, `xaml`, `axaml`, `csproj` or `sql`
  code fence.** ColorCode, the syntax highlighter, ships two malformed color
  values in its own style dictionaries (`#FF#E6E6E6` for XML element names, and
  an unprefixed `FFFF00FF` for SQL system functions). Parsing either one threw
  while the code block was being drawn, and an exception in a render pass takes
  the whole process down — so the document died the moment such a fence
  scrolled into view. Malformed values are now normalized, and anything still
  unparseable renders unstyled instead of crashing.
