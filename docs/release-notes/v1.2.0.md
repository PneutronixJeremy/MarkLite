## Added

- **Reopen last session** (Options menu, on by default) — the files you had open
  come back the next time MarkLite starts, on the paragraph you were reading.
- The Help menu shows which version you are running.

## Fixed

- Opening a second file brings the MarkLite window to the front, instead of
  blinking in the taskbar.
- Resizing the window keeps your place in the document.
