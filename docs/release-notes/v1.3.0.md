## Added

- **Wide scroll bars** (View menu, on by default) — scroll bars keep their full
  thumb and track instead of shrinking to a thin strip when the mouse is away.
- **Resizable contents sidebar** — drag the divider between the sidebar and the
  document; double-click it to reset. The width is remembered.
- **Drag tabs to reorder** — grab a tab and slide it along the strip; the order
  is kept with your session. With many documents open, tabs now wrap onto
  extra rows instead of scrolling sideways.
